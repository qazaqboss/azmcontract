# WPP Жанаозен — тендерный гид АЗМ

Статический сайт по трём запросам KCOI (проект 526H00, ВЭС 77 МВт):

- `index.html` — главная: 3D-площадка, сводка, матрица решения, калькулятор цены, график, реестр рисков, гайд по подаче, текстовый гид по сайту и баннер со ссылкой.
- `orders/cold-warehouse.html` — холодный склад (исходный разбор, без изменений).
- `orders/warm-warehouse.html` — тёплый склад (исходный разбор, без изменений).
- `orders/kpp-abk.html` — КПП и АБК (исходный разбор, без изменений).

Разборы встроены в главную страницу во всю высоту; каждый можно открыть и отдельно.

## Публикация на Vercel

Сборка не нужна: на vercel.com → Add New → Project → импортировать этот репозиторий,
Framework Preset — Other, нажать Deploy. После деплоя можно вписать постоянную ссылку
в константу `SITE_URL` в `index.html` — она попадёт в баннер и QR-код.
